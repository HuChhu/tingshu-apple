# 公开仓库安全说明

## 内容边界
本仓库是「我的听书」iOS 版的共享核心与 SwiftUI 壳的公开快照。

### 保留项（业务必需，非敏感）
- 喜马拉雅公开站点域名与 API 路径：任一抓包即可获得，且是功能实现必需
- 协议常量（如签名参数名）：公开协议字段，不含密钥
- 构造测试数据（fixtures/constructed/）：自造，与真实数据无关

### 已移除项
- 全部真实抓包响应（含第三方版权正文、真实作品/作者/主播信息、真实 ID）
- 服务器地址、端口、部署路径、密钥库信息
- 任何真实凭据、token、证书指纹

## 本仓库不含
- 任何用户数据或账号凭据
- 任何第三方版权内容
- 任何服务器运维信息

## 免责
本项目仅供学习 KMP 与 SwiftUI 跨端开发，不提供任何音视频内容。
