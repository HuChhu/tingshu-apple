## 二、CookieProvider SPI（lead 拍板架构，commonMain）
```kotlin
// commonMain：契约新增 SPI（随 Contract.kt 追加，不动既有签名）
interface CookieProvider {
    suspend fun cookie(): String?   // 当前可用 cookie 串；null=无登录态
    suspend fun refresh()           // 失效时由引擎调用，实现方自行决定刷新策略
}
```
- 注入点：SearchEngine 构造参数追加 cookieProvider（默认 object : CookieProvider { null }，匿名行为与 M1 完全兼容）
- JVM spike 实现：BridgeCookieProvider——读桥的凭据文件（BRIDGE_DATA_DIR/cookies.json 同构），**凭据不进 git 不进文档**，路径走环境变量
- iOS 实现（M4，iOS席口径）：WKWebView 官方页登录 → 显式拷 HTTPCookieStorage.shared
- 引擎行为：cookie() == null 且端点需要登录 → SourceErrors.Auth，**不重试**；401/isNeedLogin → 调 refresh() 一次后按分类返回 Auth（不硬冲）

## 三、动作二：bookDetail（bridge get_book_detail 语义逐条对齐）
- 详情 URL：`{MOBILE_BASE}/mobile-album/album/page/ts-{nowMs}?albumId={id}&page=1&pageSize=1`（mobile UA + m.ximalaya.com referer）
- 曲目 URL：同模板 `page={page}&pageSize={pageSize}`；**曲目索引数学**：baseIndex=(page-1)*pageSize，index=baseIndex+i+1
- 曲目归一（对拍基准 normalize_track）：trackId←(trackId,id)、title←(title,trackTitle)、durationMs←(duration,length)、cover←(cover,coverLarge)+CDN 拼接（复用 SearchRoutes.coverUrl）
- 专辑归一：复用 M1 AlbumNormalizer（含 4 扩展键；trackCount 回退链不变）
- §18.1 已知事实：该端点已收紧为需登录（ret:50 请登录）→ bookDetail 走 CookieProvider；匿名 402/50 → Auth 分类（ErrorClassifier 复用，无新分类）
- 契约映射：bookUrl 形态 = `https://www.ximalaya.com/album/{albumId}`；解析出 albumId → 惰性参数语义：loadEpisodes=false 只拉详情页（pageSize=1），true 才拉曲目；loadFullPages=false 只拉当前页，true 循环翻页直到集数=trackCount 或空页（每页间天然过 RequestThrottle，≤1rps）
- maxPage 语义（§19.1）：bookDetail 返回 BookDetail 不带 maxPage，分页由 trackCount 推导（ceil(trackCount/pageSize)）

## 四、动作三：播放地址（1–3 级提取器思想）
| 级 | 思想 | M2 落法 |
|---|---|---|
| 1 直链 | 曲目数据自带可播 URL | mobile-album 曲目 JSON 若含直链字段（url/playUrl 族）→ 直接采纳，零额外请求 |
| 2 HTML 解析 | ksoup 抓网页曲目页 | **预留接口不实现**（ksoup 0.2.0 已定版，网页曲目页当前非主路线） |
| 3 JSON API+签名 | 官方播放接口 + Cookie | 主路线：`{WEB_BASE}/revision/play/v1/audio?ptype=1&id={trackId}&xmSignType=1`，WEB_UA + Referer=www.ximalaya.com + Cookie |
- 播放响应解析：data 节点 src/url/playUrl 回退链（对拍 bridge get_audio_url）
- ExtractedAudio.expiresInSec=3600 → 契约字段 expiresInSeconds=3600；文案「地址带时效，请立即使用」随 hint 语义进文档
- headers 规则（§19.2 纪律落地）：
  - audio URL host ∈ {*.ximalaya.com, *.xmcdn.com} → 注入 {User-Agent: WEB_UA, Referer: https://www.ximalaya.com/}
  - 其他 host → **headers 必须为空 map**（错配测试用例写进单测）
- AudioExtractor 实现 = XimalayaAudioExtractor（级1→级3顺序尝试；级间不做自动重试，级3失败按 ErrorClassifier 分类返回）

## 五、错误与限速（复用 M1 全部基线，零新增机制）
- RequestThrottle 单例贯穿三动作（详情 1 页 = 2 请求，全量翻页 N+1 请求，天然限速）
- WebSearchBudget 不涉及（播放/详情不在搜索端点）；但 M2 顺带补：预算落盘持久化 + 人工恢复入口（对齐 risk.py 状态文件语义，M1 遗留项）
- 分类复用：ErrorClassifier 四态 + NotFound（专辑不存在：详情响应无 album 节点 → SourceErrors.NotFound，对齐 bridge「专辑不存在或已下架」文案）
