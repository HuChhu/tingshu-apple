# 「我的听书」苹果版 · 最终方案 v1.4

> 2026-11-21 · 五席评审通过（arch/legal/product/qa/ios 全部「带条件通过」，零否决，条件已全部落盘）
> 交付目标：iPhone 上能用的「我的听书」——搜索、详情、播放、后台听、锁屏控制

## 一、定案

**方案 B：KMP 共享核心 + SwiftUI 原生壳**
- 一套 Kotlin 核心引擎（搜索/详情/播放地址解析/签名/限速），iOS 用原生 SwiftUI + AVPlayer
- 依据：tingshu 的 CustomSources 引擎本机实测纯 JVM 可编译（105 class，BUILD SUCCESSFUL）；同一抽象已有「JVM 库 + ximalaya-bridge 服务端」两个活实例，KMP 是第三个，不是空中楼阁
- 周期 4–6 周；第一周只碰 JVM 侧（本机就能跑，不等 Mac）
